# 角色图集生成指南：用 AI 绘图工具做出竞品级彩色宠物

设备端角色管线已就绪（批 1）：8 个状态槽位、上传即显示、状态自动切换。
本文档解决最后一环——**画出高质量的图**。适用于即梦、Midjourney、DALL·E、
可灵、豆包等任何 AI 绘图工具。

## 一、规格（硬性）

- **尺寸**：320×480 竖版（生成 2:3 或 9:16 再裁剪缩放均可）
- **格式**：JPG，≤120KB（导出质量 80-90 一般正好）
- **文件名**（决定映射到哪个状态，上传时按名识别）：

| 文件名 | 小屏显示时机 |
|---|---|
| pet_working.jpg | 会话执行工具/生成中（角色打字/专注） |
| pet_thinking.jpg | 思考中/等你确认（角色托腮/疑问） |
| pet_sleeping.jpg | 凌晨自动睡觉（角色蜷睡+Zzz） |
| pet_sleepy.jpg | 深夜犯困（角色半眯眼） |
| pet_greeting.jpg | 开机/整点问候（角色挥手，显示 3 秒） |
| pet_happy.jpg | 任务完成庆祝（角色开心，显示 4 秒） |
| pet_error.jpg | 会话出错（角色沮丧/惊讶） |
| pet_idle.jpg | 空闲待机（角色端坐） |

不需要 8 张全做——只上传做好的几张，缺的状态自动回落像素宠物。

## 二、提示词模板（每个状态一段，替换动作描述）

```
皮克斯风格 3D 渲染，一只胖乎乎的橘色虎斑猫拟人角色，站在一张小木桌前，
<动作描述>。深蓝色夜晚科技感背景（深蓝渐变，微弱星点和电路纹理），
柔和轮廓光。角色居中略偏上，占画面约 60%，下半部分留出深色简洁空间
（将叠加显示状态文字）。竖版 2:3。可爱、圆润、大眼睛、高光瞳孔、
橘色虎斑条纹、粉色内耳、腮红。无文字、无水印、无边框。
```

各状态的动作描述替换：
- **working**：双爪在一台发光的小笔记本电脑上专注打字，屏幕蓝光映在脸上
- **thinking**：一只爪托着下巴，眉头微皱，头顶漂浮一个问号气泡
- **sleeping**：蜷成一团闭眼熟睡，头顶漂浮 Zzz
- **sleepy**：半眯着眼打瞌睡，身体微微歪斜
- **greeting**：一只爪举起挥手，开心大笑
- **happy**：双爪举起欢呼，周围漂浮小爱心
- **error**：吓一跳后仰，耳朵下垂，头顶一个大红叉
- **idle**：安静端坐，平静地看向前方

## 三、一致性的三个技巧（8 张像同一个角色的关键）

1. **能垫图就垫图**：先生成一张满意的 working 主图，之后每张都把它作为
   参考图/垫图（即梦「参考生图」、MJ `--sref`、DALL·E 编辑模式），
   只改动作描述——一致性远好于纯文字重roll。
2. **提示词只改动词，其余一字不动**：角色描述、背景描述、风格词全部保持
   逐字相同，模型才不会换角色。
3. **背景保持极简深色**：小屏是深色主题，背景越深越融合；复杂的场景背景
   会在不同状态图之间产生明显跳变（想做竞品那种「窗边小院」场景，
   等「分层角色」功能：背景一张、角色透明 PNG 一张，各自独立）。

## 四、上传

工作台 → 设置 → 宠物 → 「选择角色图（可多选）」→ 选中全部做好的图 →
自动按文件名分发到设备。同名重复上传无副作用（会刷新显示）。

「清空全部角色图」按钮可一键回到像素宠物。
