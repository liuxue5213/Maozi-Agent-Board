## 3. 仍需人工在真机确认

1. **G/B 通道错位定论（最高优先级）**：把 `PANEL_COLOR_SELFTEST` 置 1 烧录，拍一屏对照 `config.h` 判读表：
   - 红带显示蓝、蓝带显示红 → `PANEL_COLOR_ORDER_BGR = true`
   - 红带显示绿、绿带显示红 → 确认 G/B 错位，`rgb_order` 无解，需查 `LV_COLOR_16_SWAP` 与 MADCTL 组合
   - 三色均正确 → 保持 `false`，问题不在颜色序
2. **编译验证**：本环境无 PlatformIO，需本地 `pio run` 确认无 undefined symbol（新增 `render_line_h`/`label1`/`card_opa`）、flash 容量足够（字库重生成后 cn_24 约 11.9MB）。
3. **字库用字**：`cn_32`/`cn_48` 只收界面文案字，改 UI 文案后必须重跑 `gen_fonts.py`，否则新字渲染成空白。
4. **新空态观感**：图标/主文案/引导三行的实际行距与视觉重量（未在真机看过）。
5. **半透明卡片可读性**：`card_opa=30%` 时卡片文字的对比度兜底是按「卡片色叠在bg→grad 渐变中点」推算的，实机有背景图时需复核。
6. **翻拍照片的色偏**：文档 §3.3 已提醒摩尔纹是拍摄伪影，配色复核请用实机直视或 Web 设置页截屏。
