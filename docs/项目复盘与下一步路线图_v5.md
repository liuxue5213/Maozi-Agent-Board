## 0. 执行摘要

maozi-diy 已从「单屏状态显示器」→「AI 会话陪伴终端」→ 当前 **「对标竞品的通用智能陪伴板（复刻仪表 87%）」** 三连跳。本期（10-11 → 10-15）最大变化不是修 bug，而是**产品定位被重写**：从自研像素宠物，转为**逐图复刻一款竞品陪伴板**（自由页编辑器 + 角色生态 + 音乐控制器 + 用量看板 + 久坐提醒 + 多传感器）。

**五个关键结论：**
1. **定位漂移是头号风险**：原产品名「像素宠物」与当前「3D 绘本 JPEG 宠物包」「通用编辑器」在方向上是冲突的，且复刻缺乏统一 PRD，靠"竞品图 N"逐张追功能。
2. **在途改动再膨胀到 50+ 文件**（上次复盘后才收敛又反弹），提交纪律风险回到高位。
3. **协议 v0.3.2 大改**：AI 槽 4→8、新增 Now-Playing/用量/多传感器/图片通道，固件客户端强锁步，需重新真机验收。
4. **测试健康**：470 全绿，但**全绿建立在一半功能尚未合入、且真机未验收**之上——绿的是已提交部分。
5. **两条宠物渲染路径并存**（矢量 `draw_pet` + JPEG 照片包），美术与维护都需收口。

7. PETPERF：帧耗时与剩余 PSRAM 在状态接口可见，无持续上涨。
