# P0-3 固件 v0.3.2 真机验收清单

> 起草：2026-10-16 · 关联：`docs/项目复盘与下一步路线图_v5.md` §4 M0 · `docs/产品愿景与范围边界_v2.md`
> 目的：烧录最新固件（`pio run -t upload`）后，逐项核对 v0.3.2 相对旧版的新增能力与回归项。

---

## 0. ⚠️ 烧录前必读（引脚改线）

- 传感器 I²C 已从旧 GPIO47/48 改为 **SDA=2 / SCL=1（GPIO1/2）**（`config.h` / `sensors.h`）。
- **M0 基线（2026-10-15）用的是旧引脚烧录**，其八页静态留证仅代表旧引脚状态。
- **在真实硬件上验证 AHT20/BMP280/VL6180X 前，必须先用 GPIO1/2 配置重新 `pio run -t upload`**，否则 I²C 扫不到设备，`ENVSRC` 回退 `NA`，传感器验收结论无效。
- 板载 RGB 灯珠引脚 `PIN_RGB=48`（个别板为 38，`config.h` 改之）；GPIO1/2 不能再作 LED。

## 5. 传感器（AHT20/BMP280/VL6180X @ GPIO1/2，`5546922`+`4b7cd54` 等）

| 项 | 通过标准 |
|---|---|
| 温湿度 | `TEMP/HUM` 来自 AHT20，失败回退 DHT11；`ENVSRC` 显示来源（AHT20/DHT11/NA） |

| 距离 | `DISTANCE`（VL6180X）读数合理 |
| 缺失态 | 未接入/读取失败时明确显示 `NA`，不残留旧值 |
| 诊断 | 启动 `SN` 三次诊断显示探测到的 I²C 设备（none=未检测到） |
