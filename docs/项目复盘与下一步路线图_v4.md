ESP32-S3 触控状态屏（ST7796 320×480）+ Python 桌面客户端，实时反映 AI 编程会话、主机态势（CPU/温度/风扇/网络/磁盘/音乐）与像素宠物陪伴。种子用户即开发者本人。

## 5. 测试健康（已复核：全绿）

初稿记录「`test_smcpriv.py` 9 个 ERROR（PermissionError）」。**实现侧复核（2026-10-11，非 root，系统 Python 3.12）：不可复现**——全套 `317 passed / 0 errors / 50 subtests`，其中 smcpriv 模块 17/17 通过（该模块全部用例基于 tmp_path/monkeypatch，不触碰真实系统位，设计上就不需要 root）。

疑因：初稿的跑测环境是沙箱（seatbelt 对 `~/.workbuddy` 或 `/Library` 的 stat 被拒）或恰逢文件写入中途。两种场景都属**环境信号**而非代码缺陷。

**保留的预案（若再现再用）**：受影响用例加 `pytest.mark.skipif` 环境守卫，或把 `stored_interval()` 的元数据读取在测试中统一 monkeypatch 到 tmp_path，使非特权/沙箱环境优雅跳过而非报错。
