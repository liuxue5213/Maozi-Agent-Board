## 一句话愿景

**毛子（Maozi）是一块 AI 会话陪伴板（AI Companion Board）**：以像素美学为视觉语言，把"AI 在忙什么 / 宠物陪伴 / 系统用量 / 正在听什么 / 久坐关怀 / 环境传感"整合到一块 320×480 触控屏上，让桌面的 AI 工作状态可被一眼看见、可被触摸互动。

> 关键定位：**板是容器，像素宠物是默认人格，不是唯一身份。** 复刻竞品的功能被收束到"让状态可见、可互动"这一条主线。

## §1 四点决策（v2 · 已 ratify）

### 决策 1 — 产品定位声明
**保留「毛子 / Maozi」品牌，正式定位为「AI 陪伴板」，不再以"像素电子宠物"为唯一身份。**
- 代码侧已落地 `Maozi-Agent-Board`，命名无需改动。
- "像素"降级为**视觉风格标签 + 默认内容 persona**，不再是品类名。
- 对外一句话：**「你的 AI 桌面状态板，也是一只会陪你的像素宠物。」**

### 决策 2 — 宠物美术路线（canonical = 矢量，代码已确权）
**矢量 `draw_pet` 为 canonical（真·像素、PSRAM 友好、永远可用），JPEG 3D 绘本包降级为可选皮肤。**
- ✅ **本决策已在固件代码中落地**（见 `docs/宠物双渲染路径收口_R3.md` 的代码引证）：`make_pet_page` / `render_pet_page` 始终创建矢量部件，仅当 `pet_<帧>.jpg` 存在时才覆盖为皮肤。
- JPEG 包（shiba/xingli/xuebai_v2）**不废**：作为"可选皮肤"保留，受 PSRAM 预算 + 缺帧回退约束。
- 详见 R3 收口文档的残留清理成本。

### 决策 3 — 复刻范围边界（Non-goals，**v2 修正**）
> ⚠️ **v1 修正点**：v1 把"系统闹钟/外部日历"列入 Non-goals，但**设备端本地闹钟 + 日程提醒已在固件/客户端落地**（v5 §3.4 已指出该冲突）。本版将二者移出 Non-goals（标记为"已交付"），仅保留"外部云同步"为不做项。

**明确不做（本期及可预见下一阶段，遇到即拒，停止范围蔓延）：**

| # | 不做项 | 说明 / 边界 |
|---|---|---|
| 1 | 外部日历 / 待办云同步 | Google Calendar、系统提醒事项、Todoist 等**云端同步**不做；**设备端本地闹钟 + 日程提醒已交付**，不在此列 |
| 2 | 云账号 / 多设备同步 / 远程控制 | 单机桌面伴侣，无账号体系 |
| 3 | 浏览器 / 网页投屏 / 视频播放 | 设备只显示状态，不承载浏览 |
| 4 | 语音助手 / 设备端 LLM 对话 | 设备只**展示** AI 会话状态，不承载对话 |
| 5 | 第三方 IM 消息推送 | 微信 / Slack / 邮件未读推送不做 |
| 6 | 游戏 / 独立应用运行环境 | 不做运行时 |
| 7 | 多用户 / 角色权限管理 | 设备是单人桌面伴侣 |
| 8 | 计时器 / 秒表 | 设备闹钟已做，但计时器/秒表仍不做（避免范围蔓延） |

> 边界原则：**任何新功能必须先回答"它让哪块状态更可见或更可互动？"**，答不上来就进 Non-goals。

### 决策 4 — 宠物包资产管线（✅ 已落地，P1-4）
- 进仓库策略：`outputs/petpack_*/pet_*.jpg` 不入库（gitignore），`manifest.json` 入库。
- 传输校验：线路层 `IMG` 事务 CRC32 + 预检层 `web.petpack_integrity_check`（磁盘帧 CRC 与 manifest 比对）+ 单帧源 > 100KB 硬拒。
- PSRAM 预算：单帧解码 300KB × 12 anim 槽 = 3.6MB 最坏；越过即"缓存压力"软提示（LRU 兜底），非硬阻塞。
- 缺帧回退：`working_b→working`，其余→`idle`，整包不完整回落内置矢量。
- 详见 `docs/宠物包资产管线_v1.md`。
